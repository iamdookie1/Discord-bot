RP

Action commands like !kiss and !hug — hidden by default, only usable in one owner-approved channel per server.

RP commands are hidden everywhere by default — not listed in !cmds/!help, and inert outside one allowed channel per server. Only Discord user ID 1409771422011887678 can set that channel, with !allowchannelrp run inside it — there's no control for this here on purpose. Once set, !rpcmds run in that same channel lists what's available. This tab is just for configuring GIFs/messages below, which still applies wherever the channel ends up being.

Every RP command, built-in or custom, needs at least one GIF added below before it'll work — up to 10 per command, either pasted as a URL or uploaded straight from your device (videos are converted to a GIF automatically). Optionally add up to 10 custom messages too (using {author} / {target}), or leave them blank for the default phrasing. Use it as !kiss @user.
